# SQE GradeBook

GradeBook is a Java-based student grade management application developed for Software Quality Engineering laboratory work. The project stores student information and scores and will progressively implement grade-related functionality while demonstrating professional GitHub-based software quality practices such as branching, pull requests, code reviews, testing, and continuous integration.

## Installation

1. Install Java JDK 17 or later.
2. Clone the repository.
3. Navigate to `LABs/LAB#02/sqe-gradebook`.
4. Compile the Java source files.

```bash
javac -d out src/gradebook/*.java
