| TC-001 | Add a valid score | REQ-1 | A Student object exists with an empty scores list | 1. Create a Student object. 2. Call `student.add_score(85)`. 3. Check the score count. | The score is accepted and the score count becomes 1. | High | Positive / Functional |

| TC-003 | Reject non-numeric score input | REQ-3 | A score is received as text before being passed to the Java scoring method | 1. | TC-004 | Calculate average with multiple scores | REQ-4 | A Student object exists and contains scores 80, 90, and 70 | 1. Add scores 80, 90, and 70. 2. Call `average()`. | The returned average is `80.0`. | High | Positive / Functional |
| TC-005 | Handle average with an empty score list | REQ-5 | A Student object exists with no scores | 1. Create a Student object. 2. Call `average()`. | The method handles the empty list safely and returns `0.0` instead of throwing an exception. | High | Negative / Functional |
| TC-006 | Calculate average with a single score | REQ-4 | A Student object exists with no scores | 1. Add score `75`. 2. Call `average()`. | The returned average is `75.0`. | Medium | Positive / Functional |

| TC-008 | Compare student names case-insensitively | REQ-7 | A Student exists with name `"Ali"` | 1. Store/search for the name `"ali"`. 2. Compare it with the existing name `"Ali"`. | The names are treated as equal regardless of letter case. | Medium | Positive / Functional |
| TC-009 | Accept maximum score boundary | REQ-1 | A Student object exists with an empty scores list | 1. Call `student.add_score(100)`. 2. Check the score count. | Score `100` is accepted and the score count becomes 1. | High | Boundary / Functional |
| TC-010 | Accept minimum score boundary | REQ-1 | A Student object exists with an empty scores list | 1. Call `student.add_score(0)`. 2. Check the score count. | Score `0` is accepted and the score count becomes 1. | High | Boundary / Functional |
| TC-011 | Convert a mid-range score to a grade letter | REQ-8 | Grade conversion functionality is available and a score of `75` is provided | 1. Pass score `75` to the grade conversion method. 2.
