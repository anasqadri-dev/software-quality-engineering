# SQE Library Management

A library management project created as part of **Lab 01** for the **Software Quality Engineering (SQE)** course.

## Project Description

The purpose of this project is to establish a GitHub-based software development workflow and demonstrate the basic **Software Quality Engineering** practices introduced in Lab 01.

The project repository includes source code, test cases, documentation, screenshots, and project configuration files organized according to a standard project structure.

## Project Structure

```text
sqe-library-management/
├── .github/
│   └── workflows/
├── docs/
├── screenshots/
├── src/
├── tests/
├── .gitignore
├── LICENSE

```
