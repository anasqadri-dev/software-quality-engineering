# Software Quality Engineering

A semester-long repository containing my **Software Quality Engineering (SQE)** laboratory assignments, submission files, and lab projects.

This repository is maintained throughout the semester to keep all SQE laboratory work organized in a single GitHub repository.

---

## 📚 Repository Purpose

The purpose of this repository is to:

- Organize all Software Quality Engineering laboratory work.
- Maintain a single repository for the entire semester.
- Keep individual lab tasks organized and easy to navigate.
- Store final lab submission PDFs.
- Store source code, tests, documentation, and other files required for each lab task.
- Track laboratory work throughout the semester.
- Maintain a clean and consistent GitHub workflow.
